# Firestore Data Contract (Current Implementation)

This document describes the **current** collection schema used by the parent dashboard and Android child app.

## 1) `parents/{parentUid}`
Current usage: reserved for parent profile/settings. Parent auth is Firebase Auth email/password.

### Required fields
- No strict required fields enforced in current client code.

### Example
```json
{
  "email": "parent@example.com",
  "displayName": "Parent Account",
  "createdAt": "<timestamp>",
  "updatedAt": "<timestamp>"
}
```

## 2) `children/{childUid}`
Child record linked during pairing.

### Required fields
- `parentUid` (string)
- `paired` (boolean)
- `pairedAt` (timestamp)
- `pairingCode` (string)
- `updatedAt` (timestamp)

### Optional/common fields
- `deviceName` (string)
- `platform` (string)
- `monitoringActive` (boolean)
- `blockApp` (string | null)

### Example
```json
{
  "parentUid": "parentUid123",
  "paired": true,
  "pairedAt": "<timestamp>",
  "pairingCode": "123456",
  "updatedAt": "<timestamp>",
  "deviceName": "Google Pixel 7",
  "platform": "android",
  "monitoringActive": true
}
```

## 3) `children/{childUid}/commands/{commandId}`
Parent command queue consumed by child.

### Required fields
- `type` ("set_limit" | "block_app" | "unblock_app")
- `status` ("pending" | "handled" | "failed")
- `createdAt` (timestamp)

### Fields by command type
- common: `appPackage` (string), `appName` (string)
- `set_limit`: `maxMinutes` (number), `enabled` (boolean)
- `block_app`: `reason` (string)

### Child-updated fields
- `handledAt` (timestamp)
- `errorMessage` (string, only for failed)

### Example
```json
{
  "type": "set_limit",
  "appPackage": "com.instagram.android",
  "appName": "Instagram",
  "maxMinutes": 30,
  "enabled": true,
  "status": "pending",
  "createdAt": "<timestamp>"
}
```

## 4) `pairing_codes/{code}`
Generated by parent dashboard and redeemed by child app.

### Required fields
- `code` (string)
- `parentUid` (string)
- `status` ("pending" | "used")
- `createdAt` (timestamp)
- `expiresAt` (timestamp/date)
- `usedByChildUid` (string | null)
- `usedAt` (timestamp | null)

### Example
```json
{
  "code": "123456",
  "parentUid": "parentUid123",
  "status": "pending",
  "createdAt": "<timestamp>",
  "expiresAt": "<timestamp>",
  "usedByChildUid": null,
  "usedAt": null
}
```

## 5) `time_requests/{requestId}`
Child-created requests, parent-approved/denied.

### Required fields
- `childUid` (string)
- `deviceName` (string)
- `appName` (string)
- `appPackage` (string)
- `requestedMinutes` (number)
- `status` ("pending" | "approved" | "denied" | "applied")
- `createdAt` (timestamp)

### Parent response fields
- `approvedMinutes` (number | null)
- `parentResponse` ("approved" | "denied" | null)
- `resolvedAt` (timestamp | null)

### Example
```json
{
  "childUid": "childUid123",
  "deviceName": "Samsung SM-A54",
  "appName": "YouTube",
  "appPackage": "com.google.android.youtube",
  "requestedMinutes": 15,
  "approvedMinutes": null,
  "status": "pending",
  "parentResponse": null,
  "createdAt": "<timestamp>",
  "resolvedAt": null
}
```

## 6) `usage_sessions/{childUid}/sessions/{sessionId}`
Usage snapshots uploaded by child app.

### Required fields
- `packageName` (string)
- `appName` (string)
- `startTime` (unix ms)
- `endTime` (unix ms)
- `duration` (number, seconds)
- `syncedAt` (unix ms)

### Example
```json
{
  "packageName": "com.instagram.android",
  "appName": "Instagram",
  "startTime": 1715580000000,
  "endTime": 1715580900000,
  "duration": 900,
  "syncedAt": 1715580905000
}
```
